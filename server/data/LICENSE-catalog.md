# 天体百科目录归属与使用说明

- 真实目录基础数据来自 Mattia Verga 等维护的 OpenNGC，以及 NASA Exoplanet Archive（PS 默认记录）。获取日期：2026-11-20。原始来源、固定版本地址、论文引用与字段说明详见 `catalog-sources.json`。
- OpenNGC 原始数据采用 CC BY-SA 4.0；本项目保留来源、作者、许可与更改说明。其整理与派生部分继续按同许可提供。
- NASA 档案中的科学测量、目录记录与原论文引用保留原归属。不得把本项目的集合许可理解为 NASA 标识或论文的统一授权。
- 新增的中文精选介绍、原创世界设定与数据整理贡献采用 CC BY-SA 4.0。程序代码、第三方图形库许可不因此改变。
- 本项目将缺失字段保持为空，质量上／下限单独标记，未用模型外观补造观测事实。
- 地球展示底图来自 NASA Blue Marble，在用户提供的 4.0 页面中本地提取并缩小至 1024 像素。地球光照与动态不是实时遥感；其他行星或月球纹理可以是该参考页面的程序化素材。
- 动态图像为程序化可视化，不是实测照片或精确天文历表。科学设想与原创想象分别标识，不属于真实天体目录。
