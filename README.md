# 万象寰宇 · 星海图鉴与天体百科（Cosmic Atlas & Encyclopedia of Celestial Bodies）

> 一款融合 **WebGL2 / Three.js 实时多尺度宇宙模拟**、**天体物理撞击实验室** 与 **25,262 条实测+设想天体百科数据库** 的全栈交互式深空观测平台。无需账号、无需登录，开箱即用，原生支持桌面端与手机局域网双端自适应体验。

---

## 核心功能一览

### 1. 七重宇宙尺度实时 3D 模拟（L0 – L5）
从地月系一直漫游至可观测宇宙纤维网，支持 360° 自由拖动旋转、滚轮缩放、天体点击锁定追踪、电影自动巡航、纯净录屏模式（`H`）与高清截图（`S`）：

| 尺度 | 场景名称 | 核心模拟与视觉特性 |
| :--- | :--- | :--- |
| **L0** | **地月系** | 真实地月质心绕转与太阳风视差穿行；**192×128 高精 3D 顶点凹凸地球**（喜马拉雅/青藏高原、安第斯、落基、阿尔卑斯山脉真实三维隆起 + 法线浮雕 + 流动海洋洋流/河流/湖泊 + 南北极 3D 动态绿紫极光）；五大真实经纬度地球地标精准定位（喜马拉雅山脉、亚马逊雨林、太平洋深海、撒哈拉沙漠、北极冰盖与极光区）并自带防穿模外球面绕切与脉冲信标。 |
| **L0-B** | **地球微缩生态地表** | 近地自动触发降落提示或一键切入：144×144 细分雪山峡谷地形、流动瀑布与 280 颗顺流河道波光粒子、有机动态海浪与跃水鲸群、盘旋飞鸟、林间鹿群。 |
| **L1** | **太阳系 · 穿行银河** | 基于速度 Verlet 积分的真实太阳系 N 体轨道与日心/银河双参考系切换；八大行星按各自公转周期（0.24–164.8 年）自适应延展**分色三维螺旋穿行轨迹** + 随动椭圆参考轨道 + 星际视差星流 + 日球层弓形激波 + 银河累计航程（AU）读数；专属太阳系视角（银河穿行侧视 / 黄道俯瞰 / 内太阳系 / 外太阳系）。 |
| **L2** | **黑洞视界（M87*）** | 基于史瓦西光线弯曲近似的实时 GLSL 相对论着色器：事件视界阴影、明亮光子环、多普勒增亮差速吸积盘、旋入尘埃轨迹与可切换双极相对论等离子体喷流。 |
| **L3** | **星系尺度** | 85,000+ 粒子差速旋转星系与近似平坦旋转曲线，支持 **银河系棒旋 / 仙女座 M31 / 草帽星系 M104 / 室女座 M87 / 车轮碰撞星系** 五种形态实时切换，标注太阳系位置与星系际视差星流。 |
| **L4** | **拉尼亚凯亚超星系团** | 8 个软化 N 体引力节点相互演进，26,000+ 星系背景与 640 颗高亮物质流粒子沿引力势阱汇聚向巨引源。 |
| **L5** | **可观测宇宙纤维网** | 42,000+ 密度节点与星系纤维网、简化 ΛCDM 尺度因子 `a(t)` 物理空间膨胀 / 共动参考切换、随空间扩张的参考环与宇宙微波背景（CMB）。 |

### 2. 天体撞击与高能物理控制实验室（14 种实验 + 叠加损伤系统）
- **4 类自然撞击**：小行星撞击、彗星撞击、大气空爆、动能撞击器（支持岩石/冰尘/铁镍材质、入射角、直径、速度、大气开关与陆地/海洋表面选择，内置指数大气减速、气动烧蚀与碎裂模型）。
- **6 类高能与辐射实验**：核能量释放、反物质湮灭（`E = 2mc²`）、激光烧蚀、伽马暴照射、戴森恒星光束、相对论撞击体（洛伦兹动能模型）。
- **4 类引力与科幻演出**：潮汐掠过、微型黑洞、二向箔二维降维展开、真空相变泡。
- **真实感与叠加特效**：
  - 大气再入等离子烧蚀锥 + 双层扩散地表地震波/大气冲击波 + 340+ 弹道抛射幕帘 + 上升蘑菇烟柱。
  - **16 槽位持久熔岩撞击坑着色器**：重复撞击邻近区域自动合并扩大熔岩破口并二次增亮；累计撞击逐步触发**全球核冬尘埃霾层**、**地壳熔岩裂谷**与 **3 次以上重击形成行星碎屑轨道环**。
  - 支持 **`⚡ 3连发叠加`** 齐射按钮、落点瞄准模式、单目标复原与全局重置；且右侧面板严格按当前宇宙尺度上下文显示对应控件，互不干扰。

### 3. 星海百科（25,262 条天体数据库 + 实时 3D 特效 + 演化时期 + 互动问答 + 横向对比）
按 **`B`** 键或点击顶部 **「天体百科」** 即可开启（开启时自动暂停后台宇宙模拟以节省性能与电量）：
- **全量分层检索**：收录 **25,262 条**记录——包含 **24,302 条现实观测天体**（OpenNGC 深空星表 + NASA Exoplanet Archive 系外行星档案 + **104 条中文深度精选**）、**384 条科学设想** 与 **576 条原创想象世界**；顶部支持 **「全部 / 现实宇宙 / 科学设想 / 想象世界 / ☆ 收藏」** 切换与 10 大天体分类筛选、中英文/NGC/Messier 编号即时搜索与多维度排序。
- **高精差异化 3D 动态视图 + 实时视觉调节器**：
  - 为恒星（沸腾米粒对流 + 日珥磁环 + 多层日冕）、星系（12,500+ 粒子旋臂 + 玫瑰红 H-II 诞星区）、黑洞（湍流吸积盘 + 多普勒增亮 + 引力透镜拱弧 + 柔光相对论喷流）、行星/熔岩/冰巨星/星云/星团/彗星/脉冲星/戴森群/环世界分别打造专属 GLSL 着色器与差异化缩略图。
  - 内置实时调节栏：**亮度（0.6×–2.4×）**、**特效（0.3×–2.2×）**、**转速（0×–3.0×）**、**`☀ 全景展示 / ◐ 深空实境`**（支持所有天体的高对比暗空与昼夜晨昏线切换）、**`✦ 星空：开 / 关`**（1,400 颗多光谱繁星 + 36 颗十字星芒亮星）与 **`⛶ 放大观赏`**。
- **天体演化时期动态推演（含自动播放）**：
  - **太阳与类太阳恒星**：原恒星/形成期（分子云 + 湍流原行星盘 + 双极等离子喷流）→ 主序星时期（当前）→ 红巨星时期（剧烈膨胀逼近地球轨道参考环）→ 行星状星云与白矮星（青蓝/紫红双层膨胀星云壳 + 蓝白白矮星核）。
  - 同时为大质量恒星（含超新星爆发/脉冲星）、岩质行星（冥古宙熔岩期→早期海洋→当前→红巨星炙烤）、气态巨行星、星系（原星系→旋臂→碰撞并合→椭圆星系）、黑洞（坍缩→类星体→当前→休眠）、星云与星团均内置可交互 3D 演化时间轴。
- **深度科普档案与点击弹出互动问答**：
  - 顶部 **4 宫格身世档案卡**（发现者/提出者、起源与形成机制、空间位置与归属、观测与探测来源）+ **6 大通俗科普解析章节**（含光年/满月尺度/温度边界等生活化类比）。
  - 每条天体配备 **3–4 道定制互动思考题**，点击问题卡片即刻弹出 **「💡 详细解析」答案浮层**，支持连续切题与已读追踪。
- **多天体横向对比（`/api/compare`）**：支持将最多 3 颗任意天体加入对比栏，一键弹出多维参数横向对比表。

## 技术栈与架构设计

| 层级 | 采用技术与实现说明 |
| :--- | :--- |
| **3D 图形与着色器** | **Three.js（ES Module）**、**WebGL2**、自定义 **GLSL 顶点/片元着色器**（3D 地形顶点置换、切空间法线微浮雕、相对论光线弯曲黑洞、湍流吸积盘与等离子喷流、16 槽位撞击熔岩坑、极光帷幕、动态河流洋流）、`EffectComposer` + `UnrealBloomPass` 后处理辉光、`OrbitControls`。 |
| **物理与天文数值模型** | 速度 Verlet（Velocity Verlet）辛积分 N 体引力计算、开普勒轨道要素映射、指数大气层阻力/烧蚀/空爆近似模型、简化 ΛCDM 宇宙学尺度因子演进、确定性伪随机数（PRNG）星场与星系生成器。 |
| **前端界面与样式** | 零框架原生 ES Module + 预编译静态 Tailwind CSS + 自定义深空毛玻璃润色层（[polish.css](.work/polish.css)）、统一线性 SVG 图标体系、原生 `<dialog>` 模态框、Web Audio API 实时合成深空声场与撞击音效、电脑/手机双端自适应布局（支持本地离线模式与服务端 API 自动无缝切换）。 |
| **后端服务** | **Node.js (>= 24)** + **Fastify 5**，提供 gzip 静态压缩缓存、安全响应头与全只读 REST API（无需账号或密钥）。 |
| **数据库与缓存** | 默认内置 **SQLite（`node:sqlite` WAL 模式）** 持久化全量 25,262 条天体记录；支持通过 `.env` 无缝接入现有 **PostgreSQL（`pg`）**（独立 `cosmic_catalog` schema，不触碰其他表）；集成 **Redis（`ioredis`）** 独立命名空间查询缓存（不可用时自动优雅降级）。 |
| **构建与数据管线** | Python 组装构建脚本（[.work/assemble.py](.work/assemble.py)）将模块化源码组装为可独立分发的 [cosmic_atlas_3_0.html](cosmic_atlas_3_0.html)；Node.js 数据构建与打包脚本（[catalog-core.mjs](server/scripts/catalog-core.mjs)、[catalog-pack.mjs](server/scripts/catalog-pack.mjs)）；`node:test` 自动化后端测试套件。 |

## 快速开始

### 环境要求
- **Node.js 24+**（使用内置 `node:sqlite` 与 `--env-file-if-exists`）
- **Python 3.10+**（仅在修改前端源码需要重新组装 HTML 时使用）
- 可选：**Redis**（默认连接 `redis://127.0.0.1:6379`，未启动自动跳过） / **PostgreSQL**（通过 `.env` 配置）

### 1. 安装依赖与启动服务（默认 8090 端口）
```bash
npm install
npm start
```
启动后访问：`http://localhost:8090`（Windows 用户也可直接双击 `启动星海百科.cmd`）。

### 2. 手机局域网访问
电脑与手机处于同一 Wi-Fi 时：
```bash
npm run start:lan
```
或双击 `启动手机访问.cmd`，随后在手机浏览器打开终端输出的 `http://<局域网IP>:8090`。

### 3. 常用开发与测试命令
```bash
# 重新生成中文精选与设想天体库（catalog-curated.json / catalog-imagined.json）
npm run catalog:core

# 重新打包离线完整目录（encyclopedia-catalog.js / catalog-offline-core.json）
npm run catalog:pack

# 从 .work/ 模块化源码重新组装主页面 cosmic_atlas_3_0.html
npm run build

# 运行全套后端 API / SQLite / Redis 自动化测试
npm test
```

### 4. 可选 PostgreSQL 配置
复制 `.env.example` 为 `.env`，填入已有数据库配置即可自动切换至 PostgreSQL 存储：
```env
HOST=127.0.0.1
PORT=8090
DATABASE_URL=postgresql://user:password@127.0.0.1:5432/cosmic_atlas
REDIS_URL=redis://127.0.0.1:6379
```

## 后端 API 接口一览

所有接口均为只读公开查询，无需认证：

| 方法与路径 | 功能说明 |
| :--- | :--- |
| `GET /api/health` | 服务健康检查、存储模式（SQLite / PostgreSQL）与 Redis 缓存命中统计 |
| `GET /api/catalog/stats` | 返回天体总数（25,262）、各范围与各分类统计及目录版本号 |
| `GET /api/catalog/sources` | 返回公开天文星表来源与许可元数据 |
| `GET /api/objects` | 分页检索天体（支持 `q`、`realm`、`kind`、`sort=featured\|name\|distance\|radius`、`page`、`limit`） |
| `GET /api/objects/:id` | 获取单颗天体完整详情（含 4 项身世档案、6 大科普解析章节、参数行与互动问答） |
| `GET /api/objects/random` | 按当前范围与分类随机抽取一颗天体 |
| `GET /api/compare?ids=a,b,c` | 最多同时对比 4 颗天体的定量参数与来源信息 |
